# Roteiro do vídeo (5–8 min)

1. 0:00–0:30 — Cada integrante aparece na webcam e diz nome completo.
2. 0:30–1:20 — Mostrar o projeto e explicar Java 17, Spring Boot, JPA, H2 e DTOs.
3. 1:20–2:00 — Mostrar os relacionamentos: Profile 1:N Project; Project N:N Technology; Project 1:N Feedback.
4. 2:00–5:30 — No Postman executar: POST profile; GET profile; POST technology; GET technologies; POST project; GET projects.
5. 5:30–6:10 — Mostrar uma requisição inválida (ex.: name vazio) e o HTTP 400 de validação.
6. 6:10–7:00 — Mostrar H2 Console e as tabelas.
7. 7:00–7:30 — Encerramento e agradecimento.

Frase final: “Concluímos a primeira etapa da DevShowcase API, contemplando modelagem relacional, persistência, DTOs com validação e endpoints REST básicos.”
